# CAREERONIX
#### A modern web application for job searching and recruitment management. Built to deliver a smooth user experience, it includes JWT based authentication, an intuitive recruiter dashboard, and an automated notification system.


### LIVE LINK: https://job-portal-web-app-mauve.vercel.app/<br/>

## 🚀 Features<br/>

#### 👤 Candidate<br/>

    Browse available jobs
    Apply for jobs
    View applied job status
    Secure authentication

#### 🧑‍💼 Recruiter<br/>

    Recruiter login & dashboard
    Create and manage job postings
    View job applications
    Manage candidate applications

## 🔐 Authentication & Security<br/>

    JWT authentication using httpOnly cookies
    Auto-login with session persistence
    Protected routes for recruiters
    Secure logout

## 🛠 Tech Stack<br/>

#### Frontend<br/>
    React.js
    React Router
    Tailwind CSS
    Fetch API

#### Backend<br/>
    Node.js
    Express.js
    MongoDB
    JWT (Authentication)
    Cookie-based auth
    CORS configured securely
    Multer (file handling)
    Cloudinary (file storage)

#### 🔄 Authentication Flow<br/>

    User logs in
    Backend creates JWT
    JWT stored in httpOnly cookie
    Cookie sent automatically with requests
    Auto-login handled via /me API
